Applications open

Descendant and missed-enrollee applications

Verified rule

Class D applicants must be lineal descendants born after December 18, 1971 and not enrolled with descendant stock in another regional Alaska Native corporation. Separate Class C rules apply.

Timing Applications are open; BBNC currently publishes no closing date.

Prepare

  • Class D: relationship birth certificate and Social Security card.
  • For a minor: the child’s documents and notarized custodial consent.
  • Class C: birth certificate, Social Security card, and Certificate of Indian Blood.
