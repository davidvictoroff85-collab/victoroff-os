# Phase 0–9 delivery contract

Every phase ends with a deployable surface, an executable acceptance predicate, and a durable release
receipt. Future work is authorized by the accepted output of the prior phase, not by this concept.

| Phase | Deployable surface | Acceptance predicate | Durable receipt |
|---|---|---|---|
| Concept | Victoroff-owned public/synthetic demonstration | Repository verification suite passes; `noindex` remains active | Private repository revision and Vercel deployment |
| 0 | Authority and ownership workshop packet | BBNC signs the authority, owner, data, representation, and repository boundaries | Signed charter in a BBNC-controlled system |
| 1 | Discovery evidence and tested task model | Named shareholder tasks pass moderated usability criteria | Research repository and decision record |
| 2 | Architecture and accessible visual system | BBNC accepts one accessible direction and the contract threat model | Approved design-system and architecture release |
| 3 | Production foundation | Identity, environments, audit, recovery, and repository controls pass | BBNC-owned infrastructure release |
| 4 | Synthetic/shadow vertical slice | Signed package, quarantine, withdrawal, outage, and rollback predicates pass | Shadow release receipt |
| 5 | Communications workflow | Bounded content class is approved and released only through Stewardship | Authoritative Communications release receipt |
| 6 | Shareholder alpha | Six priority journeys pass accessibility and task-completion targets | Alpha release and outcome report |
| 7 | Complete BBNC.net beta and migration | Content, redirects, search, integrations, and rollback rehearsal pass | Beta and migration rehearsal receipt |
| 8 | Verified cutover | Exact tested revision is promoted; rollback remains executable | Cutover and rollback receipt |
| 9 | Independent operation through Omega | BBNC completes release, recovery, measurement, and improvement without vendor custody | Operations acceptance and training receipt |

Authenticated myBBNC replacement is not implied by these phases. It requires a separately authorized
program because it introduces credentials, shareholder records, and sensitive submissions.
