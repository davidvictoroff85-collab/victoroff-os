# Global Whale Transition directive disposition

Status: accepted as a proposed subordinate design and engineering invariant

The owner-provided directive dated 2026-07-23 requires one Global Whale Transition System for
meaningful internal page-to-page movement. The normalized source is
program/sources/victoroff-global-whale-transition-20260723.v1.json. ADR 0004 is the governing
repository design contract until an authorized superior source is available.

The invariant is registered beneath the current authority hierarchy. It does not amend or claim to
quote the unavailable Victoroff Constitution. It grants no deployment, DNS, custody, production,
real-data, or representational authority.

The current public site has same-page anchors only, which the directive excludes. The first code
packet therefore owns a reusable package-level engine and its visual layer. A later owned apps/os
router packet will mount WhaleTransitionProvider exactly once when qualifying internal routes exist.
